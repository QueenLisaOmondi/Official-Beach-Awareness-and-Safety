# Beach Awareness & Safety

This site is ready for GitHub Pages deployment.

## How to publish on GitHub Pages

1. Commit and push all changes to your repository.
2. Go to your repository on GitHub.
3. Click on **Settings** > **Pages**.
4. Under "Source", select the `main` branch and `/ (root)` folder.
5. Save and wait for deployment.
6. Your site will be live at `https://<your-username>.github.io/<your-repo-name>/`.

**Note:** The `.nojekyll` file disables Jekyll processing, so all files (including those in folders starting with an underscore) will be served correctly.
